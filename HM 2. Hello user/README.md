# Домашнє завдання №1 — Hello user

У цьому домашньому завданні я створив просту вебсторінку, яка запитує ім’я користувача та виводить персональне привітання.

## Що було зроблено

Під час виконання роботи я:

- створив структуру проєкту з окремими папками для CSS та JavaScript;
- підключив файл стилів `style.css`;
- підключив файл скрипта `script.js`;
- додав заголовок `Hello user` на сторінку;
- за допомогою `prompt()` запросив ім’я користувача;
- зберіг введене ім’я у змінну;
- сформував персональне повідомлення;
- вивів результат за допомогою `alert()`;
- додав просте оформлення та ефект збільшення заголовка при наведенні.

## Структура проєкту

```HM1/
├── css/
│ └── style.css
├── js/
│ └── script.js
├── index.html
└── README.md
```

## HTML

У файлі index.html я створив основну структуру сторінки, додав заголовок та підключив CSS і JavaScript.

`<h1 class="hi">Hello user</h1>`

## JavaScript

У файлі script.js використовується суворий режим JavaScript:

`"use strict";`

Після відкриття сторінки програма запитує ім’я користувача:

`const name = prompt("Введіть ваше ім'я");`

Потім створюється текст привітання:

`let words = "Hello, " + name + "! How are you?";`

Готове повідомлення виводиться у вікні alert():

`alert(words);`

Наприклад, якщо користувач введе ім’я Guest, програма покаже:

`Hello, Guest! How are you?`

## CSS

Для заголовка я додав:

вирівнювання тексту по центру;
бірюзовий фон;
білий колір тексту;
розмір тексту 50px;
плавну анімацію;
збільшення заголовка при наведенні курсора.

```.hi {
display: flex;
align-items: center;
justify-content: center;
background-color: aqua;
color: aliceblue;
font-size: 50px;
transition: 2s;
}

.hi:hover {
scale: 2;
}
```
